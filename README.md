# 🌿 REHATARA
### Sistem Manajemen Cuti Karyawan

REHATARA merupakan aplikasi berbasis web yang dirancang untuk mempermudah dan mengelola proses administrasi cuti karyawan secara terstruktur, praktis, dan transparan.

Melalui REHATARA, proses pengajuan, verifikasi, hingga persetujuan cuti dapat dilakukan dalam satu platform yang terintegrasi.

## ✨ Fitur Utama

- **Manajemen Pengguna** — Mengelola data pengguna dan hak akses.
- **Manajemen Divisi** — Mengelola divisi dan anggota karyawan.
- **Pengajuan Cuti** — Memfasilitasi karyawan dalam mengajukan berbagai jenis cuti.
- **Verifikasi Cuti** — Memungkinkan Ketua Divisi memeriksa dan memverifikasi pengajuan cuti.
- **Persetujuan HRD** — Memfasilitasi persetujuan akhir oleh HRD.
- **Manajemen Kuota Cuti** — Memantau sisa kuota cuti karyawan.
- **Riwayat Cuti** — Menampilkan riwayat pengajuan dan status cuti.

## 👥 Hak Akses Pengguna

REHATARA memiliki empat jenis pengguna:

| Role | Hak Akses |
|---|---|
| Admin | Mengelola pengguna, divisi, jenis cuti, dan hari libur. |
| Karyawan | Mengajukan cuti dan melihat riwayat serta kuota cuti. |
| Ketua Divisi | Memverifikasi pengajuan cuti anggota divisi. |
| HRD | Memberikan persetujuan akhir pengajuan cuti. |

## 🔄 Alur Pengajuan Cuti

1. Karyawan mengajukan permohonan cuti melalui sistem.
2. Ketua Divisi melakukan pemeriksaan dan verifikasi.
3. HRD melakukan pemeriksaan dan memberikan keputusan akhir.
4. Status pengajuan dapat dipantau melalui aplikasi.

Khusus pengajuan cuti oleh Ketua Divisi, permohonan diteruskan langsung kepada HRD.

## 🛠️ Teknologi yang Digunakan

- **Frontend & Framework:** Next.js
- **Styling:** Tailwind CSS
- **Database:** PostgreSQL
- **Language:** JavaScript

## 🚀 Cara Menjalankan Proyek

1. Clone repository:

   ```bash
   git clone https://github.com/yutss55/REHATARA.git
   ```

2. Masuk ke direktori proyek:

   ```bash
   cd REHATARA
   ```

3. Instal dependensi:

   ```bash
   npm install
   ```

4. Siapkan database PostgreSQL dan konfigurasi koneksi database sesuai pengaturan proyek.

5. Jalankan aplikasi:

   ```bash
   npm run dev
   ```

6. Buka aplikasi melalui browser:

   ```text
   http://localhost:3000
   ```
